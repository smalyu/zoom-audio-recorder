# Zoom Audio Recorder

Записывает звук Zoom и ваш микрофон — только когда он включён в Zoom — в один M4A. macOS 15+, без сети.

1. Перетащите приложение из DMG в «Программы», откройте и выдайте три разрешения.
2. Войдите в созвон → «Начать запись» → «Остановить».
3. Файл появится в «Музыка → Записи Zoom».

Прерванная запись восстанавливается при следующем запуске. Переключение mute в живом созвоне ещё не проверено вручную.

```sh
zsh scripts/build.sh    # приложение
zsh scripts/test.sh     # тесты
zsh scripts/package.sh  # DMG
```
