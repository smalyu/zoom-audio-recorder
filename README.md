# Zoom Audio Recorder

Нативное приложение для macOS 15 и новее. Записывает звук приложения Zoom и системный микрофон только когда собственная кнопка mute в Zoom показывает включённый микрофон. Результат — один файл M4A. Видео не сохраняется. Сеть не используется.

## Для пользователей

Откройте DMG, перетащите приложение в «Программы» и запустите его оттуда. Если Gatekeeper блокирует эту локальную сборку, откройте «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно».

При первом запуске разрешите доступ **Zoom Audio Recorder**, используя три кнопки в окне. Если macOS не добавила приложение в список, нажмите «+» и выберите установленное `.app`. Терминалу доступ не требуется.

Откройте Zoom и войдите в созвон. Нажмите «Начать запись», выберите место сохранения. Завершите кнопкой «Остановить и сохранить». При обычном выходе во время записи приложение сначала сохраняет звук. Закрытое окно можно открыть через значок в строке меню.

В Zoom должен быть выбран тот же микрофон, что и системный микрофон Mac. Проверяйте индикатор микрофона в рекордере. Если кнопка Zoom недоступна, микрофон заглушается. Покажите панель управления встречей, если состояние не определяется. Предупредите участников о записи.

## Разработка

Нужны Xcode Command Line Tools и macOS 15+. Внутри приложения нет Python, FFmpeg и внешних библиотек.

```sh
zsh scripts/build.sh
zsh scripts/test.sh
zsh scripts/package.sh
```

Сборка универсальная: arm64 + x86_64. Установщик находится в `build.noindex/Zoom Audio Recorder.dmg`. Python и `ds_store` нужны только для оформления установочного диска, не для запуска приложения. Проверки кодеков и создание DMG требуют обычной среды macOS; в ограниченной песочнице системные службы AVFoundation и DiskImages могут быть недоступны.

Тесты декодируют реальный AAC/M4A и проверяют тишину при mute, сохранение исходных буферов и времени, задержку дорожек, возвращение голоса после mute, звук Zoom во время mute, единственную аудиодорожку и отсутствие видео.

## Ограничения

Внешнее приложение не получает публичный API состояния mute от Zoom. Используется Accessibility: сначала собственная команда аудио в меню Zoom, затем кнопки/переключатели в окне встречи. Переводы читаются из установленного Zoom; распознанный элемент проверяется каждые 200 мс и повторно ищется при смене окна. Неактивные команды и кнопки участников игнорируются. При неизвестном состоянии микрофон не записывается. Изменения интерфейса Zoom могут потребовать обновления. Запись микрофона — исходный системный сигнал, без обработки шумоподавлением Zoom.

Служебные сборки хранятся в `build.noindex`, чтобы Spotlight не показывал их как дополнительные приложения. Диагностика `--diagnose-zoom /absolute/path/report.json` выполняется самим рекордером с его разрешением Accessibility: читает состояние и аудиокнопки, без захвата видео, изменения mute и записи голоса.

Захват выбирает только `us.zoom.xos` с PID основного процесса Zoom. Поиск по имени запрещён: имя самого рекордера тоже содержит Zoom. Диагностика сообщает PID источника захвата и PID, у которого читается состояние микрофона, чтобы проверить, что это один процесс. Сборка 5 проверена на установленном Zoom: оба PID совпадают, команда `Unmute audio` распознаётся как выключенный микрофон. Полная проверка живой записи и переключений mute ещё требуется.

Сборка подписана постоянным локальным сертификатом. Его ключ хранится в отдельной приватной связке `~/Library/Application Support/Zoom Audio Recorder Build Signing`, за пределами репозитория и установщика. Системные доверенные корни и список пользовательских связок не изменяются. Подпись привязана к сертификату и идентификатору приложения, поэтому изменения кода сохраняют ту же signing identity. При переходе со старых ad hoc сборок нужно один раз заново выдать разрешения.

Для распространения без предупреждений Gatekeeper по-прежнему необходимы Apple Developer Program, сертификат Developer ID Application и notarization. Постоянный локальный сертификат этого не заменяет. Для сборки с Developer ID передайте `SIGNING_IDENTITY` в окружении. Gatekeeper и TCC не отключаются и не обходятся. Приватную папку подписи не отправляйте коллегам.

Реальная встреча Zoom ещё требует ручной проверки: голоса собеседников, переключение mute/unmute, используемый микрофон и разрешения на новом Mac.
